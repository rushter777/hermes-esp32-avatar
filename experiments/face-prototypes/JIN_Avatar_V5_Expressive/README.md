# Jin Avatar V5 expressive prototype

V5 enlarges the eye recesses to 72×48 pixels and gives each lit eye up to roughly 30 pixels of expressive height. It uses original rendering code inspired by general animation principles; it does not copy source from either referenced copyleft eye library.

Press the ESP32-S3 **BOOT** button to advance through:

1. Neutral
2. Happy
3. Amused
4. Curious
5. Skeptical
6. Concerned
7. Annoyed
8. Tired
9. Surprised
10. Speaking demonstration

Each change interpolates smoothly. Blinking remains synchronized and automatic. The expression name appears briefly below the face and then disappears. The speaking demonstration animates the five mouth elements with temporary timing; real audio will replace that timing later.
