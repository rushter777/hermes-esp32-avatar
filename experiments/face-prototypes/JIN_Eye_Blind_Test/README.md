# Jin blind full-face eye test

This is the first controlled test for Jin V5. It leaves V4 and the earlier prototype untouched.

1. The screen briefly displays `A`, then holds the first complete face indefinitely.
2. Record your immediate reaction to A before pressing anything.
3. Press the ESP32-S3 **BOOT** button once for B, then repeat for C.
4. Press **BOOT** once more to reveal the candidate mapping.
5. Another press begins a newly shuffled blind round.

All three faces use identical plate, mouth, palette, position, and 70% aperture. Only the eye architecture changes. There is no blinking, pulsing, automatic advance, header, or footer during the face views.
